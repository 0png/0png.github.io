## Overview

A fast, offline-first unit converter covering length, mass, temperature, volume, speed, currency, and more. Installable as a PWA — works with no internet connection after the first load.

## Stack

- **Framework**: React + Vite
- **Language**: TypeScript
- **Offline**: Service worker via Vite PWA plugin
- **Styling**: Tailwind CSS v4

## Features

- 10+ unit categories, 100+ unit pairs
- Instant conversion as you type (no submit button)
- Fully keyboard navigable
- Installable on desktop and mobile
- Zero ads, zero tracking, zero server calls
